# CakeDekho Vendor App — Simple Upload Version

This version is intentionally flattened so GitHub web upload is easy.

Upload these 4 files directly to the repository root:

- `server.js`
- `package.json`
- `render.yaml`
- `.env.example`

No folders required.

## What this V1 includes
- Seller registration/login
- Seller approval
- ₹499/month marketing membership status
- Seller dashboard
- Product creation
- Shopify product sync structure
- Pune delivery areas
- Orders and earnings
- Commission calculations
- Admin payout dashboard
- Manual Mark Paid
- Shopify orders/create webhook endpoint

## What is still to be wired after deployment
- Shopify app credentials
- Actual recurring ₹499 payment collection
- Checkout delivery fee/serviceability logic
- Webhook HMAC verification before production launch
